# Running the App

## Step 1: Install dependencies

First, open a terminal and navigate to the root of the project directory. Then, run:

```sh
npm install
```

## Step 2: Start Metro

Next, you will need to run **Metro**, the JavaScript build tool for React Native.

To start the Metro dev server, run the following command from the same directory:

```sh
npm start
```

## Step 3: Build and run the app

With Metro running, open a new terminal window/pane from the root of the project, and run the following command to build and run the app on Android:

```sh
npm run android
```
_Ensure an Android emulator (requires Android Studio) is running before this step._
